How I Built a $0/Month Image Pipeline for My WordPress Plugins

By dengf | Published: September 3, 2026 | Category: Behind the Scenes

I ship WordPress image-library plugins. For the first year I paid a stock agency $60/month so my demos and docs wouldn't look empty. That's $720 a year for pictures I only half-used. So I rebuilt the whole image layer on free, API-accessible sources. Here's exactly what worked, what broke, and what I'd do differently.

The Goal

Replace the paid subscription with: (1) a free API for runtime image search, (2) a cache so I'm not hammering rate limits, and (3) a license check so I never ship something I'm not allowed to.

What Broke (and How I Fixed It)

1. Rate limits killed my demos

Unsplash's free API allows 50 requests/hour. My demo site got popular and started 429-ing. Fix: I added a local cache — fetch once, store the URL + a 24-hour TTL, serve from cache. Requests dropped ~95%.

2. License fine print

Unsplash and Pexels are free but require attribution in some contexts, and you can't sell the photos as-is. I added a per-image license tag in my DB and a footer credit builder so compliance is automatic, not manual.

3. Dead links

Free CDN URLs occasionally 404. I added a fallback chain: Unsplash → Pexels → Pixabay. If one source is down, the next fills in. Uptime went from "mostly" to "always."

The Final Setup

Search via Unsplash API → cache 24h → render with automatic attribution → fall back to Pexels/Pixabay on miss. Zero monthly cost, and the output looks the same as the $60 plan did.

FAQ

Q: Is free really free for commercial plugins?
A: Unsplash and Pexels allow commercial use. Pixabay (CC0) is the safest. Always keep the license tag and attribution.

Q: Won't caching hurt freshness?
A: For docs and demos, a 24-hour TTL is fine. Set it shorter if you need new images daily.

Q: Did quality drop?
A: No. The free libraries have enough volume that I find a good match in the first few results.

Bottom Line

$60/month was laziness, not a requirement. A free API plus a cache and a fallback chain replaced it completely. If you're paying for stock just to fill placeholders, you're overpaying.
